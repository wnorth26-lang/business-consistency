# Contributing

We are validating one narrow thesis: developers need a simple, read-only way to verify business state across independent systems of record.

Highest-value contributions:
1. a real cross-system state failure;
2. a connector request tied to a specific invariant;
3. a reproducible bug;
4. a small engine/test/docs improvement.

Please open an issue before broad features. We deliberately do not want a general-purpose rules language, sync engine, or workflow-observability platform.
